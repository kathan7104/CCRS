# CCRS Use-Case Diagrams (Mermaid)

This folder contains Mermaid versions of CCRS use-case diagrams.

## Files

- `01-system-usecase.md` - Whole system use-case diagram
- `02-student-usecase.md` - Student actor diagram
- `03-admin-usecase.md` - Admin actor diagram
- `04-director-usecase.md` - Director actor diagram
- `05-staff-usecase.md` - Staff actor diagram
- `06-faculty-usecase.md` - Faculty actor diagram

## Notes

- Mermaid does not provide a dedicated use-case diagram syntax, so these are modeled using `flowchart LR`.
- Solid links represent actor interaction.
- Dashed links represent `<<include>>` or `<<extend>>` relationships.
